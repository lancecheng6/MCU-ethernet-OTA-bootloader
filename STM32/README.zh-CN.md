# STM32H7 OTA Bootloader

基於 **STM32H743** 的開機程式，主打 **OTA 空中升級 + 健康檢查 + 自動回滾**。
透過乙太網接收新韌體，寫入後若新版有問題會自動還原成上一個可用版本。

> **⚠️ 目前仍在開發中。**

## 功能特色

- **OTA 空中升級（乙太網）**
  - 開機按 KEY1 進選單，選 [2] 即可從 PC 下載新韌體並寫入
  - 寫入前自動做 **CRC 驗證**，錯誤就不更新
  - 新韌體寫入 Bank2（0x08100000），與 Bootloader 分開
- **健康檢查 + 自動回滾**
  - 更新後進入「測試期」，新版 App 若卡死，看門狗 5 秒後會重置
  - 重開機自動偵測到問題 ➜ 還原成上一版可用的韌體（不怕變磚）
- **互動選單**（USART 115200）
  - [1] Info（含除錯資訊）、[2] 更新、[3] Backup、[4] Restore、[5] Run、[6] Reboot、[9] QSPI 測試
- **手動備份 / 還原**
  - 一鍵把目前韌體備份到外部 Flash，隨時可還原
